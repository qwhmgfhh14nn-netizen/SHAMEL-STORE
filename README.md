# SHAMEL-STORE
SHAMEL Online Store
SHAMEL UPDATE

الملفات:
1. index.html
2. app.js
3. shamel_database.sql

طريقة التركيب من الموبايل:

1) افتح مستودع SHAMEL على GitHub.
2) خذ نسخة احتياطية من الملفات القديمة.
3) افتح index.html واضغط Edit.
4) استبدل محتواه بكود index.html الجديد.
5) احفظ التغييرات.
6) كرر نفس الخطوات مع app.js.
7) لا تحذف ملف supabase-config.js.
8) تأكد أن ملف supabase-config.js يحتوي على رابط مشروع Supabase ومفتاح anon/public فقط.
9) راجع ملف SQL وخذ نسخة احتياطية من قاعدة البيانات قبل تشغيله.
10) اختبر المتجر بحساب عميل تجريبي قبل استقبال طلبات حقيقية.

ملاحظات مهمة:

- إنشاء الطلبات يعتمد على الدالة:
  create_shamel_order(jsonb, text)

- يجب أن تستقبل الدالة قائمة المنتجات بالشكل:
  product_id
  quantity

- الدفع المتاح في هذه النسخة هو الدفع عند الاستلام فقط.

- النسخة الحالية لا تحتوي بعد على لوحة إدارة المالك أو التاجر،
  ولا نظام الاشتراكات أو التقييمات أو المحادثات أو رفع الصور.

- إعداد Google OAuth ورسائل SMS يحتاج تفعيلًا من إعدادات Supabase.

- لا تضع مفتاح service_role داخل ملفات الموقع.
